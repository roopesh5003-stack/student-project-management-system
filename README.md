# Student Project Management System

A web-based Student Project Management System developed using PHP and MySQL for managing student projects, faculty activities, project submissions, and project tracking.

## Features

* User Registration & Login
* Student Dashboard
* Faculty Dashboard
* Project Upload & Management
* Project Year Management
* Secure Database Integration

## Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* XAMPP

## Installation

1. Clone the repository.
2. Place the project inside `xampp/htdocs`.
3. Import `student_project_management.sql` into phpMyAdmin.
4. Start Apache and MySQL in XAMPP.
5. Open the project in your browser.
